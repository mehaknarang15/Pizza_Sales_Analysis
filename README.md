# 🍕 Pizza Sales Analysis Using SQL

A structured SQL project analyzing **48,620 order details** from **21,350 orders**, involving **96 pizzas** across **32 types**, to uncover key sales insights and revenue trends. The goal is to support inventory decisions, improve customer satisfaction, and drive business growth.

---

## 📂 Dataset Overview

| Table Name       | Description                  | Records |
|------------------|-------------------------------|---------|
| `orders`         | Customer orders               | 21,350  |
| `order_details`  | Items in each order           | 48,620  |
| `pizzas`         | Pizza IDs with size & price   | 96      |
| `pizza_types`    | Pizza names and categories    | 32      |

---

## 📊 Key Insights & Analysis

- Most frequently ordered pizza sizes and categories  
- Top 5 selling pizza types and their quantities  
- Category-wise total quantity ordered  
- Highest revenue-generating pizzas and categories  
- Hourly and daily order distribution  
- Cumulative revenue trends over time  
- Percentage contribution of each pizza type to total revenue  

---

## 🛠️ Tools Used

- **MySQL** 
- **Joins**, **Aggregations**, **Date Functions**
- **Data Modeling** & **Business Logic Queries**

---

## 📈 Business Impact

This analysis enables:
- Strategic inventory planning  
- Focused marketing on high-revenue pizzas  
- Time-based demand forecasting
